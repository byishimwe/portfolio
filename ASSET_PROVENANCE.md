# Asset provenance

The owner has supplied Café Bliss, IMIZI, and Quad PNG project presentations; these are now converted to WebP and installed directly in `public/`. The owner also supplied hero and sharing PNG artwork and a portrait WebP; all are now installed. No bitmap artwork, portrait, or project interface was generated by this implementation. The previously used Living Frame captures and sharing images are removed from public output; they remain recoverable in Git history and the local ignored pre-redesign backup.

The attached Café Bliss mockup is a design reference only, saved under `design-reference/case-study-themes.png`. Its inaccurate technology labels and placeholder project names are corrected in the implementation. Mockup images and its portrait are not production assets.

The original `/images/` library is untouched and remains ignored. Final owner-supplied images must be placed directly in `public/`. See [ASSET_REPLACEMENT.md](ASSET_REPLACEMENT.md) for exact paths, dimensions, placement, and activation. Existing font files continue to come from the installed Fontsource packages. The small existing vector favicon is retained with neutral colors.

The supplied presentations are owner-provided portfolio artwork, not claimed to be authenticated production-session captures. Each 1672×941 source is preserved in ignored `tmp/project-image-originals/`. The active quality-92 WebP retains its full composition; CSS crops it for the work row and uses contain on the case study. See ASSET_REPLACEMENT for sizes and conversion settings.

Hero and sharing originals are preserved in ignored `tmp/remaining-image-originals/`. Their optimized WebP files retain full resolution. The owner-supplied portrait WebP is kept byte-for-byte unchanged.
